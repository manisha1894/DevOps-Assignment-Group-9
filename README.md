## 📌 Case Study

The `case_study/` directory contains our Software Testing related assignments, notes, presentations, weekly tasks, cheatsheets, images and reference resources.

The case study focuses on understanding different levels and types of testing and their role in ensuring software quality.

## 🧪 Testing Topics

Our work covers the following major testing concepts:

* Software Testing Basics
* Manual Testing
* Automation Testing
* Unit Testing
* Integration Testing
* System Testing
* Regression Testing
* Smoke Testing
* Sanity Testing
* CI/CD Testing
* Performance Testing
* API Testing

## 🛠️ Testing Tools

The following tools are used/researched as part of our testing work:

* Selenium – Web Automation Testing
* JUnit – Unit Testing
* PyTest – Python Testing
* Postman – API Testing
* Apache JMeter – Performance Testing
* Jenkins – Test Automation and CI/CD
