# Manual Testing

## Definition
Manual testing is software testing performed by a tester without using automated testing scripts.

## Process
1. Understand requirements
2. Prepare test scenarios
3. Create test cases
4. Execute test cases manually
5. Compare actual and expected results
6. Report defects
7. Perform retesting

## Advantages
- Easy to start
- Useful for exploratory testing
- Good for usability testing
- No automation framework required

## Disadvantages
- Time-consuming
- Repetitive
- Higher possibility of human error
- Difficult for large regression suites
