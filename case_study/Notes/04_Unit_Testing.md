# Unit Testing

## Definition
Unit testing tests the smallest testable components of a software application, such as functions or methods.

## Example
A function that calculates the total price can be tested independently.

## Purpose
- Detect bugs early
- Verify individual components
- Simplify debugging
- Improve code reliability

## Common Tools
- JUnit
- PyTest
- NUnit

## Flow
Write Unit → Execute Test → Check Result → Fix Defect
