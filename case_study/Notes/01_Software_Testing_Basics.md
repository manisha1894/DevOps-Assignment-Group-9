# Software Testing Basics

## Definition
Software testing is the process of evaluating software to identify defects and verify that it satisfies specified requirements.

## Objectives
- Find bugs and defects
- Verify requirements
- Improve software quality
- Ensure reliability and performance
- Reduce development risks

## Testing Process
1. Requirement Analysis
2. Test Planning
3. Test Case Design
4. Test Environment Setup
5. Test Execution
6. Defect Reporting
7. Retesting
8. Test Closure

## Important Terms

### Test Case
A set of conditions, inputs, and expected results used to verify a functionality.

### Test Scenario
A high-level functionality or situation that needs to be tested.

### Defect/Bug
A deviation between expected and actual behavior of software.
