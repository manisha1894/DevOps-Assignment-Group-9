# Regression Testing

## Definition
Regression testing ensures that changes or new features have not introduced defects into existing functionality.

## When Used
- After fixing bugs
- After adding new features
- After modifying existing code
- Before major releases

## Example

Before Change:
Login → Working

After adding a new feature:
Login → Test again

If login still works correctly, regression testing passes.

## Automation
Regression testing is a common area for automation because the same tests may need to be executed repeatedly.
