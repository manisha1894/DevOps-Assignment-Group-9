# Smoke and Sanity Testing

## Smoke Testing

Smoke testing is a preliminary test performed to check whether a build is stable enough for detailed testing.

### Example
Check:
- Application opens
- Login works
- Main pages load
- Basic navigation works

If major functions fail, detailed testing is stopped.

## Sanity Testing

Sanity testing is a focused test performed after minor changes or bug fixes to verify that the specific functionality works correctly.

## Difference

| Smoke Testing | Sanity Testing |
|---|---|
| Broad and basic | Narrow and focused |
| Checks build stability | Checks specific changes |
| Usually performed on new builds | Usually after changes/fixes |
